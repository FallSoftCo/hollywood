# Recover an installed automatic window after its inference ended

Native window installation, Hollywood acknowledgement and inference termination
are separate durable facts. A connector observer may refuse a legitimate native
prefix after core has installed the window but before sending its acknowledgement.
Do not replace that window, retry the terminal turn or reset its pending input.

The runtime first verifies the exact original JSONL identity, unchanged prior
prefix, adjacent intent/checkpoint/installed receipt, digest and exact canonical
tail. The normal native message prefix includes core-owned AdditionalTools before
the initial-context messages. Native tool vocabulary is not a model tool result.

Only explicit lax-agent --reconcile-only maintenance may create the missing
active_installed_reconcile acknowledgement. It uses the original active-installed
operation ID and original purpose credential. Hollywood requires the accepted
original snapshot, same agent/context/thread/host, released terminal permit and
matching context-end receipt, no active/later inference, no competing refresh,
and current access to captured sources. The response uses the existing installed
receipt schema with recoveredAfterTerminal=true, availabilityRestored=false and
newExecutionAdmitted=false. It does not restore old read fences, update a role,
settle work, mark pending input handled or infer semantic sufficiency.

If a write's outcome is unknown, observe its original operation; do not resubmit.
Normal startup remains observation-only for an unacknowledged installation.
Once recorded, the existing native reconciliation protocol can observe the exact
receipt. The original held journal and failed inference remain preserved.

Qualification distinguishes read-only verification of an actual captured native
checkpoint from authenticated disposable HTTP/PostgreSQL metadata fixtures.
Those mechanical checks do not establish model comprehension or autonomy.
