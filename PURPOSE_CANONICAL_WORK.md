# Canonical Goals and purpose-separated execution

Hollywood Goal/Work/cooperation/report records remain the authoritative work
lifecycle. Context material is a bounded internal handoff, not a second acceptance
ledger. A native work assignment requires its real report before internal work
completion; independent review and Goal acceptance remain separate events.

The active reader calls the existing bounded native review reconciler every
five seconds with the installation's native capabilities. The same transaction
retains explicit review budget, material-trigger deduplication, current reviewer
and room/placement/cooperation fences, and ingests the resulting attributable
agent request. No unchanged check itself starts a model. Deliberately stopped
readers do not run this path.

An execution responsibility can await canonical Goals sourced from its exact
original request, including an explicit scoped goalOrigin publication. Ordinary
progress does not repeatedly resume its writer. Actual terminal Goal facts can
resume the same original work and history. Native source linkage also fences
premature completion and continues a consumed responsibility if the model omitted
the explicit wait call. Access loss never counts as completion. Cancellation is
terminal but is not successful acceptance. Waiting does not prevent a different
responsibility from using the same writer.

Normal reports use the original live claim and immutable native scope. A
cooperative participant may preserve unfinished work while another participant
settles an edit plan, then resume and report normally. Do not prematurely complete
an unreported work episode and fabricate a legacy binding later. The older v2
completed-unreported report reconciliation remains explicitly v2-bound;
cross-version historical migration is unqualified.

The r36 real authenticated HTTP/PostgreSQL receipt qualifies these mechanics
using rollback-only metadata fixtures. No native executor/launch facts or model
responses were fabricated. A real canonical multiagent deliverable must separately
qualify planning, shared edits, reports, independent review and original human
completion before production replacement readiness.
